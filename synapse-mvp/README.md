# synapse-mvp

This folder is the **Synapse** web app (Vite + React 19 + TypeScript). The product README, including how to run, architecture, routes, and file formats, lives at the **repository root**:

**[../README.md](../README.md)**

```bash
npm install
npm run dev
```

| Script | Command |
| --- | --- |
| Dev | `npm run dev` |
| Test | `npm test` |
| Production build | `npm run build` |

App version is `"version"` in `package.json` (currently 0.3.0). Do not use the repository root `package.json` to install or start the app.
